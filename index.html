Limit Order Book Engine & RL Market Makers

A zero-heap-allocation C++20 matching engine (4–7 ns median per operation) using a pre-allocated object pool, intrusive price levels and a direct-indexed price map, bound to Python with pybind11 over zero-copy NumPy buffers. PPO agents trained through self-play against Hawkes-clustered order flow and informed traders beat the Avellaneda–Stoikov strategy in an adverse-selection regime where it lost money. A GRU estimator recovers the hidden fair value from order flow and feeds the policy directly.

ChessLM

A small language model taught to play chess, trained entirely on a MacBook. I fine-tuned Qwen2.5-1.5B with LoRA on Apple Silicon (MLX) so one model both proposes moves and evaluates positions, then plays through an AlphaZero-style PUCT search that can never make an illegal move. It learns from its own games through expert iteration, and a retrieval-augmented coach explains each move using the Lichess opening database and vector search over chess principles. You can play it on a web board.

Polymarket Consensus Bot

Scores the top 200 Polymarket traders on win rate, profit factor and drawdown, and enters when enough qualified traders converge on a market — filtered by category, price range and freshness.
